# Case 2 Legacy Files

This directory contains historical Case 2 studies that are not part of the
current active EVP-first campaign.

Examples:

- older branch-localization sweeps
- historical `ncv` / `tol` / `nev` calibration matrices
- mixed stability+resolvent campaign configs
- shock-cleanup and resolvent-only experiments
- plot helpers tied to those historical studies

They are kept for evidence and possible reuse, but they are not the files to
launch for the current workflow.
