# Martini 2024 Fixtures

This directory is the default home for compact Martini MATLAB parity bundles
generated by `examples/martini/extract_martini_to_npz.py`.

Raw MATLAB `.mat` exports remain outside Git under `martini_examples/`. Generated
`.npz` fixtures should stay compact enough for normal repository review and are
still subject to `tests/test_tracked_file_size.py`.

## Quick Preflight

From the repository root:

```bash
.venv/bin/python examples/martini/extract_martini_to_npz.py \
    --check-fixtures
```

Full regeneration (MATLAB → `LinStab2DResults/`):

```bash
bash examples/martini/regenerate_martini_fixtures.sh
```

The command is read-only preflight. It inventories two things:

- raw MATLAB HDF5 exports under `martini_examples/`;
- compact extracted `.npz` bundles in this directory.

Both inventories must be complete before the Martini parity gate can be used as
a Phase 0 baseline.

## Expected Raw Exports

The current parity registry expects these raw files under `martini_examples/`:

```text
example_0_TestCurvilinearDerivative_results.mat
example_1_Blasius_results.mat
example_2_Jet_results.mat
example_3_Streaky_BL_results_temporal.mat
example_3_Streaky_BL_results_spatial.mat
example_3_paper_temporal_Lx2pi_nP2_results_temporal.mat
example_3_paper_temporal_Lxpi_nfloq0_results_temporal.mat
example_3_paper_temporal_Lxpi_nfloq2_results_temporal.mat
example_3_paper_spatial_Lxpi_nP2_results_temporal.mat
example_3_paper_spatial_Lxpi_nP2_results_spatial.mat
example_4_Cavity_results_direct.mat
example_4_Cavity_results_adjoint.mat
example_5_Paraboloid_results.mat
```

Generated by `examples/martini/linstab2D_scripts/run_martini_exports.sh` (requires
`LINSTAB2D_ROOT`). See `linstab2D_scripts/README.md` for the per-field contract.
`LINSTABPY_BASEFLOW_DATA_DIR`, `src/linstabpy/data/baseflows`, or the bundled
`.mat` files under `examples/martini/baseflows/` (`BL_BF.mat` for Example 3,
`Step_BF.mat` for Example 4, `M09jet.mat` for Example 2,
`Paraboloid_BF.mat` for Example 5).

Extracted LinStab2D reference NPZ bundles live under `examples/martini/LinStab2DResults/`.
Examples 0–2 ship MATLAB fixtures there (Example 1 uses split `*_values.npz` +
`*_modes.npz`; Example 2 uses a single `example_2_Jet_results.npz`). Example 3
paper campaigns use split `example_3_paper_*_results_temporal_{values,modes}.npz`
plus `example_3_paper_spatial_Lxpi_nP2_results_spatial.npz`; legacy parity
bundles `example_3_Streaky_BL_results_*` remain for `compare_martini_examples.py`.
Example 4 uses split `example_4_Cavity_results_{direct,adjoint}_{values,modes}.npz`
plus `example_4_Cavity_results_base.npz`. Example 5 uses split
`example_5_Paraboloid_results_{values,modes}.npz` (see also
`example_5_D2y_asymm_fix.md` for the mesh-layer fix this case depends on).
Python example outputs (e.g. `example_0_curvilinear_validation.npz`,
`example_1_blasius.npz`) are written next to the driver under `examples/martini/`.

## Restore Or Regenerate

If the raw exports already exist from a previous validation run, place them in
`martini_examples/` and extract the compact bundles:

```bash
LINSTABPY_WITH_H5PY=1 ./install.sh
.venv/bin/python examples/martini/extract_martini_to_npz.py
.venv/bin/python examples/martini/extract_martini_to_npz.py \
    --check-fixtures
```

If the raw exports do not exist, regenerate the full fixture tree:

```bash
export LINSTAB2D_ROOT=/path/to/LinStab2D
bash examples/martini/regenerate_martini_fixtures.sh
```

This runs `linstab2D_scripts/` MATLAB drivers, extracts to staging NPZ, then splits
into `LinStab2DResults/` (`*_values.npz` + `*_modes.npz` where applicable).
Example 3 temporal saves **50** modes; spatial saves **50** `alphas` (no spatial
mode vectors); `floquet_ext*` is omitted.

After extraction, run the parity gate:

```bash
bash run_all_examples.sh --fresh
.venv/bin/python examples/martini/compare_martini_examples.py
```

Record the git SHA, preflight output, parity report path, and any unavailable
case in the run notes before treating the fixtures as a baseline.

## Commit Policy

Do not commit raw `.mat` exports from `martini_examples/`. Commit compact `.npz`
fixtures only when they are intentionally part of the public parity baseline and
pass the tracked-file-size guard:

```bash
.venv/bin/python -m pytest tests/test_tracked_file_size.py -q --tb=line
```
