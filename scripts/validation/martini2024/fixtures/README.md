# Martini 2024 Fixtures

This directory is the default home for compact Martini MATLAB parity bundles
generated by `scripts/validation/martini2024/tools/extract_martini_to_npz.py`.

Raw MATLAB `.mat` exports remain outside Git under `martini_examples/`. Generated
`.npz` fixtures should stay compact enough for normal repository review and are
still subject to `scripts/check_tracked_file_size.py`.

## Quick Preflight

From the repository root:

```bash
.venv/bin/python scripts/validation/martini2024/tools/extract_martini_to_npz.py \
    --check-fixtures
```

The command is read-only. It inventories two things:

- raw MATLAB HDF5 exports under `martini_examples/`;
- compact extracted `.npz` bundles in this directory.

Both inventories must be complete before the Martini parity gate can be used as
a Phase 0 baseline.

These are MATLAB v7.3/HDF5 exports of the reference example outputs, not the
base-flow input files. The base-flow input files are configured separately with
`LINSTABPY_BASEFLOW_DATA_DIR` or `src/linstabpy/data/baseflows`.

## Restore Or Regenerate

If the raw exports already exist from a previous validation run, place them in
`martini_examples/` and extract the compact bundles:

```bash
LINSTABPY_WITH_H5PY=1 ./install.sh
.venv/bin/python scripts/validation/martini2024/tools/extract_martini_to_npz.py
.venv/bin/python scripts/validation/martini2024/tools/extract_martini_to_npz.py \
    --check-fixtures
```

If the raw exports do not exist, regenerate them from the upstream MATLAB
reference examples. The helper below writes a MATLAB runner into `artifacts/`
and saves only the result/log variables needed by the parity comparator:

```bash
.venv/bin/python scripts/validation/martini2024/tools/generate_martini_matlab_exports.py \
    --source-dir /path/to/LinStab2D/examples-or-baseflows \
    --output-dir martini_examples
```

Use `--matlab /path/to/matlab` when MATLAB is not on `PATH`. Add `--dry-run` to
inspect the generated runner and command without invoking MATLAB. The public
repository does not bundle MATLAB, the upstream checkout, or heavyweight raw
exports.

After extraction, run the parity gate:

```bash
bash run_all_examples.sh --fresh
.venv/bin/python scripts/validation/martini2024/tools/compare_martini_examples.py
```

Record the git SHA, preflight output, parity report path, and any unavailable
case in the Phase 0 bead before treating the fixtures as a baseline.

## Commit Policy

Do not commit raw `.mat` exports from `martini_examples/`. Commit compact `.npz`
fixtures only when they are intentionally part of the public parity baseline and
pass the tracked-file-size guard:

```bash
.venv/bin/python scripts/check_tracked_file_size.py
```
