## Two-Tier Architecture: scipy (Phase 2) → PETSc/SLEPc (Phase 3)

The codebase will support two solver backends:

**Tier 1 — scipy + scikit-umfpack (Phase 2, this plan)**
- Operator assembly: `scipy.sparse` (CSC/CSR)
- Direct solver: UMFPACK via `scikit-umfpack` (drop-in for `scipy.sparse.linalg.splu`)
- Eigenvalue solver: ARPACK via `scipy.sparse.linalg.eigs`
- Target: serial workstations, up to ~500k DOFs, matches MATLAB performance
- Zero external dependencies beyond pip-installable packages

**Tier 2 — PETSc/SLEPc (Phase 3, future)**
- Operator assembly: `PETSc.Mat` (native row-by-row insertion, MPI-distributed)
- Direct solver: MUMPS via PETSc KSP (MPI-parallel LU)
- Eigenvalue solver: SLEPc EPS (Krylov-Schur, shift-invert)
- Target: HPC clusters, 1M+ DOFs, MPI scalability
- Requires PETSc/SLEPc installation with complex scalar type (`--with-scalar-type=complex`)

**Design for dual-backend support:**
- Mesh, coefficients, boundary conditions, base flow loaders are backend-agnostic (pure NumPy arrays)
- The assembly module (`assembly.py`) and solvers (`resolvent.py`, `eigenvalue.py`) are the only backend-dependent modules
- Phase 3 adds parallel versions: `assembly_petsc.py`, `resolvent_petsc.py`, `eigenvalue_slepc.py`
- A top-level `backend` flag selects scipy or petsc at runtime
- The scipy tier remains the default (no PETSc installation required to use the package)

**PETSc/SLEPc installation notes (Phase 3):**
- Requires `--with-scalar-type=complex` (the LNSE operator is inherently complex-valued)
- `install.sh` will add an optional `--with-petsc` flag that compiles PETSc+SLEPc from source
- petsc4py and slepc4py installed via `pip install petsc4py slepc4py` after PETSc/SLEPc are configured

### Step 1: SBP Pole Conditions
**Files**: `linstab2d/mesh/sbp.py`
**Source**: `Dmats_SBP.m:89-166`

Add `build_sbp_pole_matrices(n, dz, order)` returning 4 additional matrices:
- `D1s` (symmetric first derivative, Mohseni & Colonius)
- `D1a` (antisymmetric first derivative)
- `D2s` (symmetric second derivative)
- `D2a` (antisymmetric second derivative)

The pole conditions enforce `f(-r) = ±f(r)` at r=0 by modifying boundary closure stencils:
- Symmetric: `a_p1s(j,:) = a_interior[w-j:] + fliplr(a_interior[:w-j])`
- Antisymmetric: `a_p1s(j,:) = a_interior[w-j:] - fliplr(a_interior[:w-j])`

### Step 2: Mesh Extensions
**Files**: `linstab2d/mesh/mesh.py`
**Sources**: `CreateMesh.m`, `AddDW2mesh.m:150-161`, `MeshMask.m`, `DeformMesh.m:132-253`

**2a. y-symmetry** (`Mesh.create` with `y_symmetry=True`):
- Store additional matrices: `Dy_symm`, `D2y_symm`, `Dy_asymm`, `D2y_asymm`
- Plus mixed: `Dxy_symm`, `Dyx_symm`, `Dxy_asymm`, `Dyx_asymm`
- Integration weights: `W_symm`, `W_asymm` (3/4 factor at r=0 for asymmetric)
- Built by calling `build_sbp_pole_matrices` for y-lines touching the symmetry axis

**2b. x-periodicity** (`Mesh.create` with `x_periodicity=True`):
- Extend grid by `fd_order` ghost points on each side
- Build FD matrices on extended grid
- Contract back using periodicity projection matrix B
- Remove right endpoint from domain (avoid duplication)

**2c. Mesh masking** (`Mesh.mask(mask_array)`):
- Accept boolean mask (True=keep)
- Update `used_ind`, `ngp`
- Rebuild FD matrices via `_build_operators` (hole detection handles gaps)
- Find interior mask edge via 2D convolution → `idx['mi']`
- Remap all boundary indices to reduced index space

**2d. Full 2D deformation — general curvilinear transformation** (`Mesh.deform(X_new, Y_new)`):

This is the general curvilinear coordinate transformation from `DeformMesh.m:132-253`. It maps an arbitrary physical domain (X_new, Y_new) onto the computational domain via the full 2×2 Jacobian. This enables conformal mappings (Example 5 parabolic), multi-step stretching (Example 4 cavity), and any future non-orthogonal grids.

- Compute full 2×2 Jacobian: `J[i,j] = d(X_new,Y_new)[i] / d(ξ,η)[j]` using existing Dx, Dy
- Compute Jacobian derivatives: `dJ[i,j,k]` = second derivatives of the mapping
- Invert: `Ji = inv(J)` pointwise, `det = J[0,0]*J[1,1] - J[1,0]*J[0,1]`
- First derivatives: `Dx_new = Ji[0,0]*Dx + Ji[0,1]*Dy`, `Dy_new = Ji[1,0]*Dx + Ji[1,1]*Dy`
- Second derivatives with curvature correction Q tensor:
  ```
  D2x_new = axx*D2x + axy*Dxy + ayx*Dyx + ayy*D2y + Q[0,0,0]*Dx + Q[0,0,1]*Dy
  ```
  where `aij = Ji^T ⊗ Ji` contracted coefficients and `Q[i,j,k] = Ji[j,l]*dJi[i,k,l]`
- Update `W *= |det(J)|`
- If `y_symmetry=True`: also transform symmetric/antisymmetric variants (Dy_symm, Dy_asymm, etc.)

**Key design note**: The coefficients module (`coefficients.py`) is coordinate-system agnostic — the curvilinear transformation is fully absorbed into the deformed FD operators. The assembly module passes deformed Dx, Dy, D2x, D2y, Dxy to the coefficient function, which sees only "differentiation in physical space" regardless of the underlying grid topology. This means no separate curvilinear coefficient formulation is needed; the general Jacobian transformation in `Mesh.deform` is sufficient for arbitrary geometries.

### Step 3: Spatial Filters
**Files**: `linstab2d/mesh/filters.py` (NEW)
**Source**: `GetFilter.m`, `CreateFilter.m`, `filter_O10_diffMat.m`

- 10th-order implicit filter matrices M, F per line
- 2D filter = separable (y-filter ∘ x-filter)
- `filter(v)` = `solve(M_y, solve(M_x, F_x @ (F_z @ v)))`
- `filter_ct(v)` = conjugate transpose version
- Store as `mesh.filters`
- For `alpha_filter=0` or `'none'`: identity (current default)

### Step 6: Assembly Extensions (axy model, Floquet)
**Files**: `linstab2d/operators/assembly.py`
**Sources**: `GetLinProblem.m:139-143`, `CreateDiffMatrices_Axy.m`

**6a.** Add `_create_axy_diff_matrices(mesh, m)`:
- Build 5-block diagonal operators DR, D2R, DZ, D2Z, D2RZ
- Block assignment depends on m:
  - m=0 → [sym, asym, asym, sym, sym]
  - m=1 → [asym, sym, sym, asym, asym]
  - m≥2 → all asymmetric
- DZ, D2Z = `kron(I_5, Dz)`, `kron(I_5, D2z)`

**6b.** Extend `build_lnse_operator` with `model='2D'|'axy'` and `floquet_exp=0.0`:
- For `'axy'`: call `_create_axy_diff_matrices`, use cylindrical coefficients
- For Floquet: modulate `DZ → DZ + iβI`, `D2Z → D2Z + 2iβDZ + (iβ)²I`
- Energy norm for 'axy': multiply weights by r (cylindrical volume element)

### Step 7: Eigenvalue Solver
**Files**: `linstab2d/solvers/eigenvalue.py` (NEW)

`temporal_eigenvalues(L0, n_modes, target, W_diag=None)`:
- Compute ω eigenvalues of `L0 / (-1i)` near `target`
- `scipy.sparse.linalg.eigs` with shift-invert (`sigma=target`)
- UMFPACK factorization for the shift-invert

`adjoint_eigenvalues(L0, n_modes, target, W_diag, invW_diag)`:
- Compute eigenvalues of `inv(W) @ L0.conj().T @ W`
- Same shift-invert strategy

### Step 8: Spatial Stability
**Files**: `linstab2d/operators/spatial.py` (NEW), `linstab2d/solvers/spatial_eig.py` (NEW), `linstab2d/boundary_conditions/dirichlet.py`
**Sources**: `GetSpatialLinProblem.m`, `BC_Dirichlet_SpatialStability.m`

**8a.** `build_spatial_operator(mesh, bf, model, floquet_exp)`:
- Build L0 at three α values: α=0, α=+δ, α=-δ (via Floquet modulation)
- Extract R0 = L0(α=0), R1 = (L0(+δ) - L0(-δ))/(2δ), R2 = L0(+δ) - R0 - R1
- Construct doubled-space: Lc=[0,I;-R0,0], R=[I,0;R1,R2], Lw=[0,0;-iI,0]
- Double all boundary indices

**8b.** `apply_dirichlet_spatial(Lc, R, idx, borders, variables, ngp)`:
- Same logic as `apply_dirichlet` but zeros rows/cols in both Lc and R

**8c.** `spatial_eigenvalues(Lc, Lw, R, omega, n_modes, target)`:
- Form L = Lc + ω·Lw
- Solve generalized EVP: `eigs(L, R, k=n_modes, sigma=target)`
